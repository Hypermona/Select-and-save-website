## 5. Frequently Asked Questions (FAQ)

### Is Select & Save free?
Yes, Select & Save is completely free to download and use with zero subscription fees, hidden cloud limits, or account registration requirements.

### How does local Chrome AI work?
Select & Save uses Chrome's experimental Prompt API (`window.ai.languageModel`) powered by Gemini Nano. AI processing takes place on your local machine, keeping your personal notes 100% private.

### What if my browser does not have Chrome AI enabled?
Select & Save includes an intelligent local search fallback engine that instantly indexes and streams matching snippets based on titles, tags, content keywords, and domain folders.
